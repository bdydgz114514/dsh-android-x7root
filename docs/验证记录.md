## 三、明确**未验证**的部分（不要当成已验证）

- **v114 / v115 没有任何真机运行时验证**：未在真机上安装运行过，因此「知识库三级降级实际生效」「APatch 机型能探测到 root」「OEM 识别在真实 ROM 上返回正确分支」都只是**静态可确认**，不是运行时确认。
- **未在非 ColorOS / 非 Android 14 的设备上跑过**：MIUI/HyperOS、EMUI、OneUI、OriginOS、Flyme 的保活指引来自公开的 ROM 设定路径，未能逐台核对。
- **未验证 16 KB 页大小（Android 15+ 部分设备）与 32 位设备**：这两类需要重新编译原生运行时，属已知不支持范围。
- **未验证 Shizuku 通道**：开发机上 Shizuku 始终未授权。
- **未实测**：定时任务在 Android 12+ 的精确闹钟行为、多用户/工作资料场景、平板/折叠屏布局。

## 四、如何复核

```bash
# 1) 从 Release 下载 APK 后，自己核对 SHA-256
sha256sum DeepSeekHarness-X7Root-v1.7.5-x7root.7.apk
# 期望：fcc2ce39155c525a9191194a3483aa2f258cecc00d197b32acd1d427533eb667

# 2) 拆包确认补丁在成品里
7z e DeepSeekHarness-X7Root-v1.7.5-x7root.7.apk assets/mobile.js
grep -c structuredClone mobile.js     # > 0

7z e DeepSeekHarness-X7Root-v1.7.5-x7root.7.apk assets/payload.zip
7z e payload.zip '*/dsh-tool-shizuku/lib/*' -oout
grep -c detectOem out/root-tools.js   # > 0
```
